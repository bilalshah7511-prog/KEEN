# KEEN — Checkout Skin Demo

PayPhi-style checkout drawer skin for [KEEN Footwear](https://www.keenfootwear.com) (Outdoor Voices pattern).

## Font

**Melun Medium only** (`public/fonts/Melun-Medium.otf`). No other typefaces.

## Run

```bash
npm install
npm run dev
```
